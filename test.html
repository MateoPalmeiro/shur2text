🧪 Página de Prueba de Shur2Text

Esta es una página de prueba para el UserScript Shur2Text. Simula un formulario de respuesta rápida de Forocoches.

Respuesta Rápida (Simulada)

ℹ️ Instrucciones:
  1. Instala el UserScript shur2text.user.js en tu gestor de userscripts
  2. Recarga esta página
  3. Deberías ver un popup flotante "Shur2Text - BBCode Helper"
  4. Escribe texto en el popup y aplica formatos BBCode
  5. Usa el botón "Insertar" para añadir el código al área de texto de arriba
⚠️ Nota: Esta es solo una página de prueba local. El script está diseñado para funcionar en forocoches.com y www.forocoches.com
