🧪 Página de Prueba de Shur2Text

Esta es una página de prueba para el UserScript Shur2Text. Simula un formulario de respuesta rápida de Forocoches.

Respuesta Rápida (Simulada)

ℹ️ Instrucciones:
  1. Instala el UserScript shur2text.user.js en tu gestor de userscripts (Tampermonkey, Violentmonkey, etc.)
  2. Recarga esta página
  3. Deberías ver un popup flotante "shur2text - Forocoches Text Helper"
  4. El popup tiene dos modos de edición:
    • [T] Modo Técnico (BBCode): Editor de texto plano con botones BBCode y transformaciones de texto
    • [V] Modo Visual (WYSIWYG): Editor visual con formateo en tiempo real
  5. En Modo Técnico, puedes activar la Vista Previa haciendo clic en el botón [<>] para ver cómo se renderizará el BBCode
  6. Escribe y formatea tu texto usando los botones de la barra de herramientas
  7. Usa el botón "Copiar" para copiar el BBCode al portapapeles o "Insertar" para añadirlo al área de texto de arriba
  8. El popup es arrastrable (arrastra desde el título) y minimizable (botón [_])
  9. La posición, estado de minimizado y modo seleccionado se recuerdan entre sesiones usando localStorage
✨ Características Principales:
  • Modo Técnico: Soporte completo para BBCode de Forocoches (negrita, cursiva, subrayado, tachado, cita, código, spoiler, listas, enlaces, colores, tamaños, alineaciones)
  • Modo Visual: Editor WYSIWYG con conversión automática a BBCode
  • Vista Previa en Vivo: Panel lateral que renderiza el BBCode en tiempo real (solo en Modo Técnico)
  • Transformaciones de Texto: Mayúsculas, minúsculas, alternancia de mayúsculas/minúsculas
  • Selector de Color: Paleta de colores con muestras predefinidas y selector personalizado
  • Persistencia: Posición, estado y preferencias guardadas automáticamente
⚠️ Nota: Esta es solo una página de prueba local. El script está diseñado para funcionar en https://forocoches.com/foro/*. En esta página de prueba, el textarea debe tener id="vB_Editor_QR_textarea" o name="message" para que la función "Insertar" funcione correctamente.
